How 1-Gateway routing executes

Every request traverses four deterministic stages in Go before reaching an upstream provider.

01 / INGRESS

Single Port Compatibility

Accepts /v1/chat/completions, /v1/messages, /v1/responses, and /api/chat behind port :20128 while proxying management UI routes to Next.js.

02 / UNIFICATION

Pool & Window Budgeting

Resolves bare names (auto, deepseek-chat, deepseek-uncensored), strips cross-provider thoughtSignature tags, and trims oversized tool histories atomically.

03 / EXECUTION

OAuth Refresh & Keccak PoW

Renews Antigravity OAuth tokens proactively, solves DeepSeek Web DeepSeekHashV1 PoW locally, and routes kilo-gateway :free models with zero auth overhead.

04 / RECOVERY

Cooldown & SQLite Telemetry

Locks rate-limited models temporarily on 429/5xx, falls back to the next healthy channel, and records token usage inside WAL-mode transactions.
